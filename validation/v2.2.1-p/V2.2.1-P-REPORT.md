# v2.2.1-p 构建与验收报告

记录日期：2026-10-14。基于已完成的 v2.2.1-webui（含创建后标签显隐修复）制作 Windows 10/11 x64 桌面版，沿用 v2.1-p 的 WinForms / WebView2 启动器、首次自动初始化及发布方式。本次按用户要求发布 GitHub 正式 Release，v2.2.1-webui 保持 Latest。

## 已完成的检查

56 项模型、测量、渲染、存储及路径隔离测试全部通过。43 项浏览器检查通过：原有 v2 交互 17 项，基础交互 7 项，新测量流程 13 项，标签显隐专项 6 项。它们覆盖任意起点连续点取、同起点快捷点取、直线和投影、参考更新、尺度标定、分组、CSV 数据、标签隐藏与恢复、旧对象转换、保存、PNG 及便携包。

真实 EXE 完成 8 组基础功能检查，含名称与图标、多图导入、非活动图片的关闭状态、圆形局部放大和独立样式、Ctrl+S、中文 PNG/便携包接口、窗口预览、正常退出及停止服务。另完成 4 组真实 EXE 测量检查：连续独立端点、参考及标定、创建后标签显隐和撤销重做、参考更新及 WebUI v4 项目互通。桌面运行时 7 组检查通过，覆盖单 EXE 无附属 config 的启动、草稿重启恢复、单实例、CLI、异常退出清理、Node 损坏修复和应用资源损坏修复；修复后原测试项目继续存在。

首次运行在空白测试配置中强制从 nodejs.org 下载 Node.js 22.23.3，ZIP 与 node.exe 均核对官方 SHA-256。内嵌的 1610 个文件按安装清单核对通过，图片处理依赖、中文字体和服务启动检查成功。依赖安装使用独立目录，用户无需 npm 或 Setup。当前系统已有 WebView2，检测及复用已验证。

对照检查确认 17 个模型、测量、渲染等核心文件逐字一致；仅调整 App 的桌面桥接和版本名称、API 草稿库、服务版本及端口、导出内置字体路径。npm 依赖锁文件除版本标识外完全一致，77 个 WebUI 发布源码文件与已有清单一致，5 个历史 Windows ZIP 的 SHA-256 保持原样。

## 发布结构与使用

根目录仅包含生物图片编辑器.exe、使用指南.html、README.txt 和文档文件夹。技术说明、许可、CLI、人工示例及校验清单放入文档。EXE 内嵌界面、服务、锁定生产依赖、字体与图标；默认数据目录为 %LOCALAPPDATA%\Bio-Picture-Editor\v2.2.1-p\，默认端口 4324。旧版数据独立保留，迁移请导出并导入 .biozip。

打包脚本逐文件记录 SHA-256，发布校验脚本核对 ZIP、EXE、图标、根目录结构和无个人数据。最终 ZIP 哈希及实际输出以同目录 package-results.json 为准。

## 留给用户的检查

用户要求跳过后续交互测试，因此 Windows 原生“另存为”流程未完成最终验证；PNG、便携包和 CSV 的实际保存对话框操作留给用户检查。对应数据生成、PNG 渲染和便携包重开已通过自动检查。原生保存检查的中断记录保留在 desktop-measurement-attempt.json，未记为通过。

缺少 WebView2 的全新 Windows 安装流程未在本机端到端实测；启动器已包含 Microsoft 官方安装程序下载、签名校验、静默安装及重试流程。不会为测试卸载本机 WebView2。

本次没有继续进行新的桌面或浏览器交互测试。最终文件整理后只进行发布内容和哈希核对。
