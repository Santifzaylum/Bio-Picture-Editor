# Bio-Picture-Editor v1.1

Bio-Picture-Editor（界面名称：图注工坊）是一个在 Windows 本机运行的生物医学图片标注工具，适合为组织切片照片、医学大体照片和实验配图添加文字与图形标注。支持保存可继续编辑的项目、导出原分辨率 PNG，以及通过本地文件和命令行接口与 Codex 协作。

图片在本机处理，编辑器不会自动上传图片。首次安装需要联网下载依赖，初始化完成后，核心编辑功能可以离线使用。

## 下载与安装

本程序包为 **Bio-Picture-Editor-v1.1.zip**，解压后的文件夹为 `Bio-Picture-Editor-v1.1`。项目仓库：[Santifzaylum/Bio-Picture-Editor](https://github.com/Santifzaylum/Bio-Picture-Editor)。

当前提供 Windows x64 轻量版程序包，约 17 MB。压缩包包含应用源码、启动脚本、中文字体、示例和操作指南，不附带 Node.js 或预装依赖。

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11，64 位 x64 |
| 运行环境 | Node.js 22.12 或更新版本，包含 npm |
| 浏览器 | 推荐使用 Microsoft Edge |
| 安装目录 | 普通可写目录，支持中文与空格路径 |
| 网络 | 首次安装依赖时需要联网 |

1. 下载上面的 `Bio-Picture-Editor-v1.1.zip`，右键选择“全部解压”。请完整保留解压后的文件夹。
2. 从 [Node.js 官网](https://nodejs.org/)安装符合要求的 Node.js，保留默认附带的 npm；已安装符合要求的版本可跳过。
3. 进入解压后的 `Bio-Picture-Editor-v1.1` 文件夹，双击 `Setup.cmd`。看到 `Setup complete` 后，首次初始化完成。
4. 日常双击 `启动.vbs` 或 `Start.vbs`，程序会在后台启动并打开浏览器。
5. 使用结束前保存各张图片，再双击 `停止.vbs` 或 `Stop.vbs` 停止服务。只关闭网页不会停止后台服务。

默认网址为 `http://127.0.0.1:4317/`。如果端口被占用，启动器会选择后续空闲端口、更新 `config.json` 并打开对应网址。系统禁用 VBS 时，可使用 `Start.cmd` / `Stop.cmd`。

本版本已另存为独立程序包。升级时请逐张导出 `.biozip`，或停止服务后备份 `data/projects`，再在新版导入。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 图片导入 | 打开、拖入或粘贴普通 8 位 PNG / JPEG 图片 |
| 文字与图形 | 中文、多行文字、箭头、关联引线、直线、矩形和椭圆 |
| 标注编辑 | 调整位置、尺寸、颜色、字号、线宽、实虚线、底板等属性 |
| 多图片工作区 | 一次导入多张图片，通过独立标签页切换编辑 |
| 版面留白 | 在原图四周增加空间，放置图旁说明，保留原图像素尺寸 |
| 可编辑项目 | 保存原图、结构化标注和图注，之后继续修改 |
| PNG 导出 | 按原分辨率或 2× / 4× 输出合成图，不包含选择框和控制点 |
| 便携项目包 | 导出 `.biozip`，用于备份、迁移和继续编辑 |
| Codex 协作 | 通过本地 CLI 查看项目、修改标注、生成预览和导出图片 |

多图片标签页分别保留标注、视口、未保存状态和当前会话的撤销记录。**保存、导出 PNG 和导出便携项目包都作用于当前标签页，请逐张执行。** 多图片标签页用于切换编辑独立图片；当前版本尚不支持多图拼版和批量导出。

## v1.1 操作改进

选择工具下，图片或含留白的版面超出可见范围时，空白处自动显示抓手，左键拖动即可平移。鼠标移到已有标注或控制点上时优先选择和编辑对象。绘图工具仍用于创建标注；原空格加拖动平移已取消，中键平移保留。Ctrl+点击用于增加或取消多选；Shift 继续用于绘图约束和大步微调。

## 开始标注

打开 `examples/example.biozip` 体验示例，或导入自己的图片。选择左侧工具添加标注，在右侧调整文字与样式；按 `V` 切换选择工具，双击文字编辑内容。需要图旁说明时，在“版面与留白”中增加空间，再添加文字。

完成后按 `Ctrl+S` 保存可编辑项目，再导出 PNG。PNG 是合成后的图片；如果希望以后继续编辑标注，请同时保存项目或导出 `.biozip`。

| 操作 | 快捷键 |
| --- | --- |
| 打开 / 保存 | Ctrl+O / Ctrl+S |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y，或 Ctrl+Shift+Z |
| 选择 / 箭头 / 文字 / 直线 | V / A / T / L |
| 矩形 / 椭圆 | R / E |
| 复制 / 粘贴 / 复制副本 | Ctrl+C / Ctrl+V / Ctrl+D |
| 删除 / 取消 | Delete / Esc |
| 微调 / 大步移动 | 方向键 / Shift+方向键 |
| 多选 | Ctrl+点击（画布及右侧列表） |
| 缩放 / 平移 | 滚轮 / 选择工具下放大后的空白处左键拖动，或中键拖动 |

## 数据保存与备份

已保存项目位于程序文件夹的 `data/projects/<项目ID>/`，包含原始图片、显示资源、项目 JSON 和历史修订。PNG 导出副本位于对应项目的 `exports/` 文件夹。

浏览器自动草稿可以恢复多个标签页及编辑内容，但依赖浏览器和访问网址；切换浏览器或端口后不会共享草稿。草稿不能替代显式保存。迁移或升级前，建议逐张导出 `.biozip`，或停止服务后备份完整 `data/projects` 目录。

## 支持范围

当前面向普通 8 位 PNG / JPEG 图片。暂不支持 TIFF、DICOM、全切片、多通道、高位深图片、多图拼版、比例尺测量和自动识别。支持图片和导出总像素最多 6400 万、输出单边最多 16384 px；实际可处理规模还取决于电脑内存。

默认导出保留原图加留白后的像素尺寸；2× / 4× 放大不会增加照片本身的细节。工具用于手动标注和配图，示例为人工测试图。
