# Bio-Picture-Editor：Windows 轻量版操作指南

版本：v1.1（2026-09-30），支持多图片标签页、自动抓手平移及 Ctrl 多选。

## 一、首次安装与日常启动

这是轻量版程序包，适用于 Windows 10／11 的 64 位 x64 电脑。为减小体积，本包不附带 Node.js、npm、已安装依赖或重复的构建页面。

1. 在 ZIP 上右键选择“全部解压”，解压到普通可写目录，例如 D:\图片标注\图注工坊。支持中文和空格路径，请完整保留整个文件夹。
2. 首次使用前安装 Node.js 22.12 或更新版本，并保留安装程序默认附带的 npm。官方下载地址：https://nodejs.org/ 。如果已经安装符合版本要求的 Node.js，可跳过这一步。
3. 在解压后的程序文件夹双击 **Setup.cmd**。它会联网执行 npm ci 安装锁定版本的依赖，再构建编辑页面；完成时显示“Setup complete”。首次初始化需要联网，耗时取决于网络；如果安装中断，修复网络后重新运行 Setup.cmd。
4. 初始化完成后，日常双击 **启动.vbs** 或 **Start.vbs**。程序在后台启动并自动打开浏览器，日常核心编辑可以离线使用。以后不需要每次运行 Setup.cmd。
5. 使用结束前逐张保存图片，再双击 **停止.vbs** 或 **Stop.vbs**。只关闭网页不会停止后台服务。

如果系统禁用 VBS，使用 Start.cmd／Stop.cmd；这会显示一个短暂命令窗口。若单位策略禁止 PowerShell 脚本，需要管理员允许该程序使用脚本，程序不会修改系统策略。

默认网址为 http://127.0.0.1:4317/ 。如果端口被占用，启动器会选择后续空闲端口并更新 config.json，自动打开正确网址。重复启动会复用本目录已有的服务。

## 二、导入与多图片编辑

点击“打开图片 / 项目”选择 PNG、JPG／JPEG，或选择 `.biozip` 可编辑项目包。可以一次选择多个文件，也可以将多张照片从文件资源管理器拖到画布中。点击画布后 Ctrl+V 可导入剪贴板图片。

画布上方显示各张图片的标签页。点击标签页切换；“添加图片”继续导入，新打开的图片不会覆盖已经打开的编辑。各张图片独立保留标注、留白、图注、缩放和平移、选中对象以及本次会话内的撤销记录。标签页的 `*` 表示尚未保存。

**保存项目、便携包、导出 PNG 都只操作当前标签页，请逐张执行。** 关闭标签页不会删除已经保存的项目，可从“已存项目”重新打开；有未保存编辑时，关闭前会提示确认。标签页用于轮流编辑独立图片。

## 三、添加与修改标注

左侧选择箭头、直线、文字、关联引线、矩形或椭圆。箭头／直线／形状用鼠标拖动绘制，文字点击放置。绘制后会自动回到选择工具；也可以按 V，或点击“选择”。

重新点击箭头或直线即可选中，拖动线条整体移动，拖动两端的蓝色控制点调整起点或终点。细线和虚线已有更宽的鼠标点击区域，缩小图片后也更容易选中，这不会加粗导出图中的线条。遇到重叠对象时，可以从右侧标注列表选择目标对象。

双击文字，在右侧“图中短标签”中修改中文和换行；右侧也能设置颜色、字号、线宽、箭头大小、实虚线和底板。关联引线从组织位置拖向文字位置，移动文字时箭头尖端保持固定；Alt+拖动可移动整组。矩形和椭圆绘制时按住 Shift 可约束为正方形和正圆。

滚轮缩放；选择工具下，图片或含留白的版面超出可见范围时，空白处显示抓手，左键拖动可平移。移到已有标注上方会自动恢复选择，拖动标注移动对象，控制点照常编辑。点击空白处取消选择；平移拖动保留选择。也可使用中键平移。绘图工具仍用于创建标注；“适应窗口”重新显示全图。需要图旁说明时，在右侧“版面与留白”中增加四周空间，再放置文字；原图像素不会为了腾出留白而被缩小。

## 四、保存、导出和迁移

编辑完成后点击“保存项目”或按 Ctrl+S。可编辑项目保存在程序目录的 `data\projects\项目ID\` 中，包含原图、显示资源、项目 JSON 和标注。图中短标签、几何坐标和图注都可继续修改。

点击“导出 PNG”，把当前底图和可见标注合成为原分辨率图片。默认按原图加留白后的实际像素输出，与浏览器窗口大小和缩放比例无关；导出不包含选中框或控制点。浏览器会下载 PNG，程序也会在该项目的 `exports` 文件夹保留副本。

点击“便携包”下载 `.biozip`，其中包含原图和可编辑标注。把它复制到其他电脑或新版程序中，通过“打开图片 / 项目”重新打开即可。升级程序时，请先把需要保留的图片分别保存为便携包；也可以停止服务后备份完整 `data\projects` 目录。

浏览器自动草稿会保存所有打开的图片及编辑内容，刷新或重新打开页面后恢复最近成功保存的草稿。草稿与浏览器、网址和端口有关，不能替代显式保存，也不会自动迁移到另一浏览器或另一端口。刷新后项目内容和视口可恢复；撤销历史只在当前会话中保留。

本 ZIP 为轻量程序发布包，附人工测试示例，未包含你原目录中的个人图片和已存项目。原有项目仍在原目录，迁移时按上述便携包方法操作。

## 五、常用快捷键

| 操作 | 快捷键 |
|---|---|
| 打开 / 保存项目 | Ctrl+O / Ctrl+S |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y，或 Ctrl+Shift+Z |
| 复制 / 粘贴对象 | Ctrl+C / Ctrl+V |
| 复制一份选中对象 | Ctrl+D |
| 删除 / 取消绘制 | Delete / Esc |
| 选择 / 箭头 / 文字 / 直线 | V / A / T / L |
| 矩形 / 椭圆 | R / E |
| 微调 / 大步移动 | 方向键 / Shift+方向键 |
| 多选 | 选择工具下 Ctrl+点击（画布及标注列表） |
| 平移 | 选择工具下放大后的空白处左键拖动，或中键拖动 |

输入文字时，字母、空格、删除和方向键用于文字编辑，不用于绘图。

## 六、故障处理和 Codex 协作

若启动提示文件缺失，请确认是“全部解压”而非仅从压缩窗口拖出启动文件，首次初始化前没有 node_modules 和 dist 属于正常情况；运行 Setup.cmd 安装依赖并构建后，这两个目录会自动生成。启动文件缺失或初始化失败时，请重新完整解压、确认已安装 Node.js，并联网重新运行 Setup.cmd；启动失败的细节记录在 `data\server-error.log`。运行目录需要可写，请勿放入 Program Files。

如果网页没有自动打开，打开 `config.json` 查看 `port`，在 Edge 中输入 `http://127.0.0.1:该端口/`。Codex 侧边浏览器也可打开同一个地址。若需要把程序发给其他人，请重新分享原始发布 ZIP，或先去除使用过程中产生的 `data`；其中包含你的图片、项目和本机会话令牌。

程序已保存完整源码。Codex 可读取 `data\projects` 下的原图、结构化 JSON 和预览，或在程序目录使用 `Codex-CLI.cmd list`、`Codex-CLI.cmd summary 项目ID` 调用程序化接口。命令行接口沿用修订号校验，修改前请先保存项目。详细模型和接口见 GUIDE.md，本版交互验证和打包说明分别见 V1.1-REPORT.md、PACKAGE-REPORT.md。

开发修改后可双击 Rebuild.cmd 重新构建界面，构建通过后刷新网页。普通使用无需运行 Rebuild.cmd；本包只监听本机回环地址，不需要登录或 API Key。
