# 生物图片编辑器 v2.2.1-p

Windows 桌面 EXE 版，独立复制自已完成的 v2.2.1-webui。模型、测量、渲染、存储和导出源码保持一致；仅增加桌面就绪与关闭桥接，更新版本标识、草稿库及默认端口。

在此目录执行 npm ci、npm run desktop:build、npm test、npm run desktop:package、npm run desktop:verify。构建流程位于 ../../platforms/windows/v2.2.1-p/；用户指南位于 ../../../docs/windows/v2.2.1-p/。发布 EXE 内嵌编译后的界面、服务、CLI、锁定生产依赖和字体，用户无需 npm。
