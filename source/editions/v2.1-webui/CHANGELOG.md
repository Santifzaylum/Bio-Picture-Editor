# 生物图片编辑器 v2.1-webui

发布日期：2026-10-03。基于 v2.0-webui 的 Windows WebUI 改进版本，保留浏览器运行方式。

- 重绘关联引线和局部放大 SVG，统一尺寸、留出边界，并保持工具文字完整显示。
- 查看原图增加明显只读提示，暂停绘制、拖动编辑、属性修改和编辑快捷键，避免隐藏状态下生成误标注；支持缩放、平移和一键返回编辑。
- 局部放大默认放在取样区域旁，两圆间的初始连接线为 32 px，并优先选择能容纳的位置。移动、控制点、复制、方向键和 CLI 统一补足四周留白，保留原图屏幕位置和已有留白。
- 取样圆内部可直接拖动取样；放大圆内部移动展示；连接线或 Alt 拖动整组。取样范围在原图边缘约束；保留半径、倍率控制点及精确坐标输入。
- 取样圆、连接线、放大圆分别设置颜色、线宽、虚线和对比描边，保存、便携包和 PNG 均保留。

默认端口 4321，草稿库 bio-picture-editor-v2.1-webui，程序和个人数据独立于 v2.0。可导入 v1.1/v2.0 便携项目包；新独立样式属性须由 v2.1 或更新版本读取，请保留升级前备份。
