# 示例图像来源

- `test-1200x800.png`、`test-6000x4000.png`：本项目脚本人工绘制的几何测试图，可自由使用。不是显微照片，不含经过验证的病理结论。
- `ordinary-photo.png`：NASA 的 Eileen Collins 照片，来自 scikit-image 0.21.0 数据集。
  - 官方数据文档：https://scikit-image.org/docs/0.21.x/api/skimage.data.html#skimage.data.astronaut
  - 下载来源：https://raw.githubusercontent.com/scikit-image/scikit-image/v0.21.0/skimage/data/astronaut.png
  - 官方数据文档将该图列为公共领域、无已知版权限制。只用于软件导入测试，不暗示 NASA 认可本软件。
- `ordinary-photo.jpg`：上述 PNG 转为 JPEG，仅用于 JPEG 导入测试。
- `example.png` 与 `example.biozip`：人工测试图及其位置标注，不作医学诊断。
- 中文字体：Noto Sans CJK SC，随字体附带 SIL Open Font License 1.1，见 `public/fonts/LICENSE.txt`。
