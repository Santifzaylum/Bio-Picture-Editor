# v2.2.1-webui 版本说明

日期：2026-10-13。基于 v2.2-webui，作为 Windows WebUI 最新版本，历史版本保留。

- 长度测量默认支持任意起点的连续两点点取；每条记录独立保存起止位置。同起点点取可选择直线或方向投影。
- 多条待测线复用已存在的比例参考；引用端点修改后实时重算，参考删除时提示失效。比例参考与尺度标定分别设置。
- 支持分组筛选、批量设置、测量列表定位、展开表格、全精度 CSV/剪贴板、名称/长度/比值/百分比组合标签，线与编号分别控制。
- 支持关联标定线、实际单位换算及标定失效提示。画布与导出倍率不改变长度数值。
- 读取旧项目时保留旧公式与数据，可撤销转换为独立测量；新测量采用 v4 项目格式。
- 发布包根目录精简，保留中文启动、停止、初始化与指南入口；完整基础操作和新功能指南来自同一份正文。

程序与浏览器草稿库独立，默认端口 4323。首次需要 Node.js 22.12+ 与 npm；运行根目录首次初始化.cmd。日常双击启动.vbs，结束时逐张保存并运行停止.vbs。本版未自动上传 GitHub。


2026-10-13 同版修正：已有测量的标签显隐入口移至新建默认设置之前，增加“显示结果标签”直接开关。Esc 结束测量后保留选择；测量列表定位进入对象编辑。新建默认值明确标示仅影响后续测量。版本号保持 v2.2.1-webui。
