# 生物图片编辑器 v2.2.1-p

本版将 v2.2.1-webui 包装为 Windows 10/11 x64 桌面程序。双击生物图片编辑器.exe，首次自动准备依赖；完整使用方法见 USAGE.md 或发布包根目录的使用指南.html。

新增功能与 v2.2.1-webui 同步：任意起点连续两点测量、同起点点取、直线与投影距离、复用比例参考、分组、尺度标定、全精度 CSV/剪贴板导出，以及创建后随时隐藏或恢复结果标签。基础标注、多图、只读原图、局部放大和独立线条样式继续提供。

新长度测量项目使用 v4 格式，v2.2.1-p 与 v2.2.1-webui 可互相导入 .biozip；旧 v2.1-p、v2.1-macweb 不能读取含新测量的 v4 项目。用户数据位于 %LOCALAPPDATA%\Bio-Picture-Editor\v2.2.1-p\。
