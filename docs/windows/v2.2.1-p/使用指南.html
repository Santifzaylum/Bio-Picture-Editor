生物图片编辑器 v2.2.1-p 操作指南

本版为 Windows 10/11 x64 本地桌面版，完整保留 v2.2.1-webui 的编辑界面和操作方式，包括基础标注、圆形局部放大、通用长度测量、比例参考、分组、尺度标定及标签显隐。

第一次使用，按这个顺序操作

  1. 完整解压 ZIP，进入 Bio-Picture-Editor-v2.2.1-p 文件夹。
  2. 双击“生物图片编辑器.exe”。初始化窗口自动解压编辑组件和字体，准备独立 Node.js 运行环境，并检查 Microsoft WebView2。已有兼容环境会复用；缺少环境时从官方下载并安装，需要联网。无需手动安装 Node、运行 Setup 或 npm。
  3. 等待初始化完成，程序会在同一窗口打开编辑界面。以后双击 EXE 会检查并复用本地环境，准备完成后即可离线编辑。
  4. 点击“打开图片 / 项目”选择 PNG、JPEG 或 .biozip。随包“文档/示例”提供基础标注和长度测量人工示例，可先用它们练习。
  5. 编辑完成后先“保存项目”，再导出“便携包”作为可移动备份，最后“导出 PNG”得到报告配图。三种文件用途不同；PNG 不能恢复可编辑对象。
  6. 逐张保存后关闭桌面窗口。程序会保存草稿并停止自己启动的本地服务；若有未显式保存的编辑，会提醒确认。

根目录仅有 EXE、“使用指南.html”、“README.txt”和“文档”文件夹。指南可离线阅读；技术资料、许可、CLI 和示例均放在“文档”。EXE 自带运行组件，单独复制 EXE 也可以启动。

安装与启动

首次缺少依赖时需要联网。Node.js 从 nodejs.org 下载并核对官方 SHA-256，WebView2 从 Microsoft 下载并核对安装程序数字签名。下载失败时窗口提供“重试”和“打开日志目录”。系统已有 WebView2 时直接复用。

程序默认把组件、数据及 WebView2 配置保存在 %LOCALAPPDATA%\Bio-Picture-Editor\v2.2.1-p\，不往发布包内写入个人数据。普通启动无需管理员权限。默认本地端口 4324；占用时会自动选择后续可用端口。日常无需打开浏览器或启动、停止脚本。

打开图片与项目

点击“打开图片 / 项目”，打开 PNG、JPEG 或 .biozip；支持一次打开多张图片、拖入图片，以及点击画布后 Ctrl+V 粘贴图片。点击上方标签页切换，各图片独立保留标注、缩放和平移、未保存状态与当前会话内的撤销记录。

保存、导出 PNG 和便携包都只处理当前图片，请逐张执行。标签页的 * 表示有未保存编辑，关闭前会提醒。已保存项目可以从“已存项目”重新打开。

基础标注与颜色设置

左侧选择箭头、直线、文字、关联引线、矩形或椭圆。线条、形状拖动绘制，文字点击放置。各工具文字右侧的图标表示对应形状，快捷键显示在图标旁。V 切换选择工具，双击文字在右侧编辑中文与多行内容。

在右侧设置颜色、字号、线宽、虚线、底板和填充。点击颜色色块打开系统颜色选择器；点击“颜色”等文字或同行空白不会重新触发选择器。系统颜色选择器可用 Esc 关闭。四种颜色行都采用相同规则。

Ctrl+点击画布对象或右侧列表增加、取消多选，可批量调整样式。Shift 在绘图时约束正圆、正方形或 45° 方向，在方向键移动时使用 10 px 步长。关联引线移动文字时保持尖端固定，Alt+拖动移动整组。

滚轮以鼠标位置为中心缩放。选择工具下，图片或版面超出可见范围时，在无标注处左键拖动平移。对象与控制点优先编辑；空白点击取消选择，平移拖动保留选择。保留中键平移，空格不用于平移。

查看原图（只读）

点击“查看原图”后，画布上方出现“查看原图 · 只读”提示，标注及控制点隐藏，绘图工具和编辑属性暂停使用。可以滚轮缩放、左键或中键拖动平移；点击、拖动、粘贴标注、删除、移动与撤销快捷键不会修改隐藏标注。打开图片、切换标签页、保存和导出仍可使用。导出 PNG 仍输出完整标注结果，不因查看原图而删去标注。

点击提示栏或工具栏的“返回标注编辑”，或在画布按 Esc，恢复正常编辑。切换到原图模式会取消尚未完成的绘制，清除选择；已完成的标注保持。

圆形局部放大

  1. 选择“局部放大”或按 M，从原图目标区域中心拖到边缘，确定取样圆。程序在取样区附近创建默认 2× 放大圆，优先选择原图内能容纳的位置，初始两圆间连线为 32 px；创建后自动适应窗口。近边缘取样时缩小半径，使取样圆完整位于原图内。
  2. 用选择工具拖动取样圆内部任意位置，移动取样区，放大圆展示位置保持；拖动放大圆内部，移动展示位置，取样范围保持。拖动可见连接线，或按 Alt 拖动圆内区域，移动整组；取样中心在原图边缘被约束。圆心控制点也可移动取样，取样圆右边控制点调整半径，放大圆右边控制点调整倍率。
  3. 右侧“局部放大设置”可精确输入倍率、半径，展开“精确设置取样中心”输入 X/Y 坐标。倍率范围 1.25×–8×；无效取样范围拒绝修改。
  4. “分别设置线条”中切换“取样圆”“连接线”“放大圆”，分别设置颜色、线宽、虚线和对比描边。点击画布相应部位也会选中其样式面板。改变一个部位不会覆盖另外两个，保存、便携包和 PNG 均保留独立样式。
  5. 移动、调整半径/倍率、复制、方向键微调和 CLI 修改均使用同一留白规则：对象或描边超出原图时自动补足左、右、上、下留白，保留已有留白。扩展左、上留白时原图在屏幕上的位置保持，画布可平移查看，点击“适应窗口”查看完整版面。自动留白不随对象移回而缩小，可在“版面与留白”中调整，但不能裁掉已有放大对象。支持复制、删除、撤销重做、隐藏、锁定和层级调整。

放大图从方向校正后的原图取样，不包含其他标注，不增加真实图像细节。坐标和半径以原图像素记录。原有输出上限继续生效：最长边 16384 px、总计 6400 万像素。

保存、导出与升级

Ctrl+S 保存可继续编辑的项目，位置为 %LOCALAPPDATA%\Bio-Picture-Editor\v2.2.1-p\data\projects\项目ID\。原始图片独立保留，display.png 是方向校正后的 8 位 sRGB 资源；project.json 记录标注和修订，history/ 保存历史 JSON。

“导出 PNG”按完整文档像素重新渲染，包含放大圆、轮廓和连线，不包含选择框与控制点。默认输出为原图加留白的尺寸，可选择 2× 或 4×；同时在项目 exports/ 留副本。“便携包”保存含原图、显示图和标注的 .biozip，用于备份、迁移与继续编辑。

新版可以打开 v1/v2/v3 项目，包括 v2.2 的比例测量。旧项目未添加局部放大时保留 version=1；添加局部放大后升级为 version=2，v1.1 编辑器会拒绝读取；设置三处独立线条后，v2.0 编辑器也不能读取扩展属性，须用 v2.1 或更新版本。迁移前保留旧 .biozip，新版本使用独立数据目录、默认 4324 端口与独立桌面草稿库。迁移旧版时请先在旧版导出 .biozip，再在新版打开；WebUI、旧 EXE 和本版的数据与草稿分别保存。

草稿约 500 ms 防抖写入浏览器 IndexedDB，保存所有已打开图片、编辑内容及视口；撤销记录不在刷新后恢复。草稿保存在独立 WebView2 配置中，与本地网址和端口相关，不能代替显式保存。分享时使用原始发布 ZIP；个人数据目录请单独备份。

故障与支持范围

初始化失败时点击“打开日志目录”，查看 desktop.log。日志、安装记录与数据位于 %LOCALAPPDATA%\Bio-Picture-Editor\v2.2.1-p\。检查网络、代理及目录写权限，再点击“重试”。已安装组件或 Node 文件缺失、损坏时，下次启动会自动重新准备；项目与草稿分别保存。

支持普通 8 位 PNG/JPEG；不支持 TIFF、DICOM、全切片、多通道、高位深、CMYK、多页图片、自动识别、多图拼版或批量导出。核心编辑在本机执行，编辑器不会自动上传图片。医学名称与区域判断仍由使用者确认。

长度测量（Q）：先完成一个例子

点击左侧“长度测量”或按 Q。默认使用“独立起点 · 连续两点测量”和“两点直线长度”。在图上点击起点、终点，完成第一条；继续点击另一处起点、终点，完成第二条。每条都有自己的端点，方向可以不同。最后按 Esc 或点击“完成连续测量”。已完成的记录保留，尚未完成的起点被取消；结束后保留刚完成测量的选中状态，方便立即修改标签。

选中测量后，在右侧输入“测量名称”和“测量分组”。拖动端点修正位置，拖动结果文字只调整标签位置，拖线条移动整条测量。展开“精确设置端点”可输入原图 X/Y 坐标。测量表中点击名称会定位并选中对象；“展开测量表”提供完整列视图。

未标定时，长度单位为原图像素 px。界面缩放、平移、留白和 PNG 的 2×/4× 导出不会改变读数。端点位置按方向校正后的原图坐标保存。

为多条测量复用同一比例参考

先测量参考线，例如命名为“参考线”；再测量待测线 A、B。选中 A，在“比例参考”中选择“参考线”，B 也选择同一参考。比值按待测长度÷参考长度计算，两条待测线可有不同起点和方向。参考线只画一次。

需要集中设置时，展开“批量设置测量”，先选择“数据与批量操作范围”，再选择“批量比例参考”并点击“应用比例参考”。范围可以是全部测量、选中测量或当前筛选结果。参考线自身不计算自己的比值，锁定对象保留原设置。

修改参考线端点后，所有关联比例实时更新。比值可以大于 1，不会被限制在 0～1。选中待测线可点击“交换分子与分母”，原参考成为分子。删除参考线后，待测长度和记录保留，比例显示“比例参考已缺失”；可重新指定或撤销删除。

同起点连续测量和投影距离

在“点取方式”中选择“同起点 · 连续点取终点”，设置一次起点，再连续点击各终点。每条仍是独立记录，共用起点只是一种点取方式，默认仍计算两点直线长度。

如需测量电泳或层析中的沿轴迁移，先画一条方向参考线。新建时选择“沿指定方向的距离”和“新建方向参考”；已有测量则先选“方向参考”，再切换“计算方式”。结果为起点到终点的位移在参考方向上的投影，横向偏移不计入。方向参考按线段起点→终点确定，负数表示反向。比例参考与方向参考可以分别选择；采用不同计算方式的分子、分母会有提示。

同起点记录可展开“精确设置端点”，勾选“修改共同起点”后一起调整关联测量的起点。未勾选时，只修改当前记录并将其独立出来。拖动整条测量也会解除它与共同起点的关联。关联记录有锁定对象时，共同起点修改被拒绝，需要先解锁。

尺度标定：把 px 换算为实际长度

测量图片中一条已知实际尺度的线段，例如比例尺。展开“尺度标定”，选择“标定测量”，输入“已知实际长度”和“标定单位”，点击“应用尺度标定”。单位可输入 nm、μm、mm、cm、m 等文本。

例如，标定线为 200 px，实际长度为 100 μm，之后 80 px 的测量显示 40 μm。标定采用标定线自身的两点直线长度。换算假定图片在使用区域内具有相同、各方向一致的尺度，比例尺必须对应当前图片。

标定线与比例参考线各自设置。改变标定会更新实际长度，比例保持原几何关系。拖动标定线端点会更新换算；删除标定线或使其长度为零后，“标定状态”提示失效，长度回到 px。点击“清除尺度标定”也可恢复像素显示。实际长度为零或负数时不能应用标定。

标签、线条、编号与数据导出

选中已有测量后，右侧最前面的“当前长度测量”提供“显示结果标签”开关，取消勾选会立即隐藏图中长度等结果文字，重新勾选可恢复；线、编号和测量数据保留。“当前测量的标签形式”可选隐藏结果标签、名称、长度、比值、百分比、长度与比例。连续创建时的“新建标签（仅影响后续测量）”只设置下一条的默认显示，不会改变已完成的记录。点击测量表或标注列表中的已有测量，会结束点取并进入该对象的编辑。“比例标签名称”可选填 Rf 等名称，默认不强制使用 R。小数位数可设 0～6。“显示测量线”和“显示测量编号”分别控制线与编号；全部关闭后仍可从测量表选中并恢复显示。这些设置同时作用于 PNG，并随项目和便携包保存。

测量表包含名称、分组、计算方式、长度、单位、比例参考、比值、百分比及状态。“筛选分组”改变可见记录；分组只整理数据，不改变端点，也不强制共同参考。“数据与批量操作范围”决定复制、CSV 导出、批量设置和批量删除的目标。选“当前筛选结果”会导出当前筛选的记录，选“全部测量”会包含其他组。

“复制测量数据”可粘贴到 Excel。“导出测量 CSV”保留完整数值精度、端点、单位、测量方式、参考 ID 与状态；显示小数位数不会截断导出数值。表格内长度显示 3 位、比值显示 6 位，属于阅读格式。CSV 默认不包含分子量、log10 或回归数据，本版本不执行拟合。

从 v2.2 升级与旧对象处理

在旧版逐张导出 .biozip，解压新的 v2.2.1-p 文件夹并双击 EXE，再用“打开图片 / 项目”导入。新版本使用独立数据目录、4324 默认端口和独立桌面草稿库。请保留旧版文件夹及便携备份。

旧比例对象继续按原公式计算：同起点按参考轴投影，不同起点按独立直线长度比。旧连续测量和分子量数据保持，可以选中原对象继续编辑，也会出现在统一测量表中。

如需使用新的参考复用与分组操作，在“旧版比例测量”中点击“将旧版对象转换为独立测量”。每个旧对象会拆成一条参考线及一个或多个独立待测记录，原有比例、样品名称和分子量保留；同起点记录采用投影方式。转换可以撤销，锁定旧对象需先解锁。转换后图上的布局改用新测量线与编号，可按需要关闭显示。

新长度测量及关联标定使用 v4 项目格式，需要 v2.2.1 或更新版本读取。仅打开旧项目不会自动转换其测量；加入新长度测量或执行转换时才升级格式。

常见问题

测量表只有 px：还没有标定，或标定参考已失效；比例计算本身不要求标定。比例栏为空：没有设置分母，或分母长度为零、参考已删除。投影长度为空：方向参考缺失或为零，需要重新指定。

进入连续测量后不能拖旧对象：先按 Esc 或“完成连续测量”，返回选择工具再编辑。点错了：未完成的一条按 Esc 取消，已完成的记录用 Ctrl+Z 撤销。隐藏全部显示后找不到线：在测量表点名称定位，再开启线、编号或标签。

移动程序文件夹前，先保存项目并导出 .biozip，再关闭桌面窗口。移动整个发布包可同时保留离线指南与技术资料；EXE 也可单独复制运行。用户数据保存在本机独立目录，不随 EXE 移动。日常无需重新初始化；已安装资源缺失或损坏时，下次启动会自动重新准备，项目数据继续保留。
