# v2.1-p 实现与验收记录

2026-10-03。本版读取并参考“读取 v1.1 WebUI 项目背景”对话中完成的 v2.1-webui，以及“打包生物图片编辑器 v1.1-p”对话中的桌面初始化、打包和交付方式。功能基线为 source/editions/v2.1-webui，桌面源码独立位于 source/editions/v2.1-p，Windows 启动器位于 source/platforms/windows/v2.1-p。

## 成品与使用方式

交付 Windows x64 生物图片编辑器.exe，以及带操作指南、示例项目、CLI 包装、图标、许可和校验文件的 Bio-Picture-Editor-v2.1-p.zip。EXE 内嵌构建后的编辑页面、生产依赖、原生图片库、中文字体和安装完整性清单，可单独运行。用户不用 npm、Setup 或源码构建。正式文件位于 releases/windows/v2.1-p/。

软件名称为“生物图片编辑器”，版本标识为 v2.1-p，Windows 文件版本为 2.1.0.0。编辑页面的主题 SVG 与 v2.1-webui 原文件相同，EXE、窗口、初始化页面使用从该 SVG 生成的 ICO/PNG，保留 16–256 px 多分辨率图层。网页呈现、工具、只读原图查看、局部放大移动、四周留白和三处独立样式沿用 v2.1-webui。

首次打开在同一窗口显示初始化进度；内置组件按清单解压校验，兼容本地 Node.js 复制到独立目录，缺失时下载锁定的官方 Node.js 22.23.3 并核对 SHA-256。WebView2 已存在时复用，缺失时下载经 Windows Authenticode 和 Microsoft 发布者校验的官方 Bootstrapper，再静默安装。初始化成功后自动进入编辑器，失败可重试。

项目、草稿和安装资源分开保存。默认根目录为 %LOCALAPPDATA%\Bio-Picture-Editor\v2.1-p\，与 v1.1-p 和浏览器版独立。默认端口为 4322；冲突时选择后续空闲端口。窗口关闭前检查所有标签页并写入草稿，停止自己启动的 Node 服务；Job Object 在桌面进程意外终止时清理其服务。

桌面适配增加了 WebView2 就绪和关闭消息桥接，并将服务字体路径改为启动器提供的 BIO_FONT_PATH，确保内置中文字体从安装目录加载。模型、共享渲染、工作区结构和项目存储逻辑保持 v2.1-webui 的实现。

## 未覆盖的环境

本机已安装 Microsoft WebView2，验证了检测、复用和真实编辑窗口；没有在完全缺少 WebView2 的干净 Windows 系统中重新做其下载、静默安装到启动的全流程。该分支沿用 v1.1-p 的实现。未在另一台 Windows 电脑、Windows ARM64 或删除 .NET Framework 的精简系统上验收。

适用 Windows 10 1607+ / Windows 11 x64，需系统保留 .NET Framework 4.6.2+。缺少运行环境时首次安装需联网，初始化后的核心编辑可离线。旧版未保存草稿不自动迁移，迁移项目应先导出 .biozip。新增独立线条属性须用 v2.1 或更新编辑器继续读取。

本报告记录本地构建与验收阶段，随包副本保留构建时状态。后续 GitHub 发布说明见仓库 V2.1-P-RELEASE.md，发布核验记录另存 validation/publishing/v2.1-p/。完整 EXE、ZIP 哈希、依赖版本和逐文件包装校验见 BUILD-MANIFEST.json 与 package-results.json。
