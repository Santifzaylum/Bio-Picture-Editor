# 生物图片编辑器 · v2.1-p

v2.1-p 是 v2.1-webui 的 Windows 桌面 EXE 版。编辑页面、键鼠操作和项目格式沿用 v2.1-webui，包括只读原图查看、圆形局部放大、四周留白扩展和取样圆、连接线、放大圆的独立线条样式。程序名称及主题图标与 v2.1-webui 一致。

完整解压 Bio-Picture-Editor-v2.1-p.zip，双击 **生物图片编辑器.exe**。首次打开显示初始化进度，自动解压内置组件、检查图片处理依赖，并准备 Node.js 与 Microsoft WebView2；完成后在同一窗口进入编辑器。用户无需手动安装 Node.js、执行 npm、构建源码或运行 Setup 脚本。EXE 也可以单独复制运行，随包文档和示例便于使用。

已有兼容 Node.js 时程序复制到自己的运行目录；缺失时下载锁定的官方版本并校验 SHA-256。缺少 WebView2 时自动下载安装经 Microsoft 数字签名验证的安装程序。首次安装缺失依赖需要联网，完成后核心编辑可离线使用；失败时可查看日志并点击“重试”。

支持 Windows 10 1607+ / Windows 11 x64，系统需保留 .NET Framework 4.6.2+。初始化器使用该系统框架，精简系统若删除了框架，需先恢复框架才能运行 EXE。

项目保存在 `%LOCALAPPDATA%\Bio-Picture-Editor\v2.1-p\data\projects\`，桌面草稿与偏好保存在同级 `webview-profile\`。新版独立于 v1.1-p 和 WebUI 的数据目录，可并行使用；迁移时在原版逐张导出 .biozip，再在新版打开并保存。v2.1-webui 的便携包及独立线条样式可直接读取。请先保存再关闭窗口；程序会检查所有标签页的未保存状态、写入草稿，并停止自己启动的本地服务。

详细操作见 [操作指南](USAGE.md) 或直接打开 **先看这里-操作指南.html**。与 ChatGPT 和 Codex 的协作流程及命令见 [协作指南](CODEX_GUIDE.md)；构建方法见 [桌面构建说明](DESKTOP-BUILD.md)，实测范围见 [验收报告](V2.1-P-REPORT.md)。

本版支持本地图片编辑和标注，图片不会由编辑器自动上传。支持普通 8 位 PNG/JPEG、多图独立标签页、原分辨率 PNG 和可编辑 .biozip；不支持 DICOM、TIFF、全切片或多图拼版。第三方组件、字体和示例许可见随包文件。
