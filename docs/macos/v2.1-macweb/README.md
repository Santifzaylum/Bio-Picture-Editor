# 生物图片编辑器 v2.1-macweb 操作指南

**更新状态（2026-10-14）：由于缺乏实际 Mac 测试，目前暂停更新。** 现有 v2.1-macweb 保留为未测试开发版及 Pre-release，已有下载、源码、使用方法继续提供；Windows v2.2.1 的新测量功能尚未同步到 Mac。


本版将 v2.1-webui 移植为 M 系列 Mac 的本地浏览器程序，要求 macOS 14 或更新版本。当前为开发版本，未进行运行测试。发布 ZIP 包含已编译的编辑页面、本地服务、Mac 图片处理组件和中文字体；首次启动自动下载独立 Node.js 运行时，用户无需安装 npm、Xcode 或编译 `.app`。

## 首次启动与日常使用

1. 完整解压 `Bio-Picture-Editor-v2.1-macweb-arm64.zip`，保留整个文件夹。双击 `启动.command`，终端窗口会显示准备进度。
2. 首次保持联网。启动器从 Node.js 官方下载锁定的 darwin-arm64 运行时，校验 SHA-256，再安装编辑组件和字体。初始化成功后打开默认浏览器。
3. 日常仍双击 `启动.command`。已安装的运行环境可重复使用；初始化后，图片导入、编辑、保存和导出可离线进行。默认从 `http://127.0.0.1:4322/` 选择空闲端口，实际地址显示在启动窗口中。
4. 结束前逐张保存或导出便携包，再点击网页右上方“退出程序”。退出前写入当前浏览器窗口全部图片标签页草稿，再停止后台服务。

程序目录里的 `core/`、`launcher/`、`release-manifest.json` 必须完整保留。运行环境安装到当前用户目录，不需要管理员权限。系统中已有 Node.js 时仍使用本版的独立运行时，不改动系统 Node。

若 macOS 阻止下载脚本打开，请根据系统提示处理。在终端进入解压目录后，也可运行 `bash ./启动.command`。若解压工具丢失执行权限，可执行 `chmod +x ./*.command` 后重新双击。系统仍阻止运行时，不应反复绕过提示；记录具体信息供后续排查。当前没有开发者证书或苹果公证。

## 图片与基础标注

点击“打开图片 / 项目”，选择普通 8 位 PNG、JPEG 或 `.biozip`；也可同时拖入多张图片，或在画布按 Command+V 粘贴图片。上方标签页分别保留标注、视口、未保存状态及本次会话的撤销记录。带 `*` 的标签页尚有未保存内容。保存、PNG 导出和便携包均只处理当前标签页，应逐张执行。

左侧保留文字、箭头、直线、关联引线、矩形、椭圆和圆形局部放大。工具文字右侧有对应 SVG 图标。线条和形状拖动绘制，文字点击放置并在右侧编辑。Command+点击画布对象或列表可增减多选；Ctrl+点击保留兼容。Shift 约束 45° 方向、正方形或正圆；关联引线移动文字时保持尖端固定，Option+拖动移动整组。

颜色、字号、线宽、虚线、描边、底板与填充在右侧设置。点击色块打开颜色选择器；点击“颜色”等文字或同行空白不会再次触发。选择器关闭行为由浏览器和系统决定，可先尝试 Esc。

滚轮或触控板滚动以指针位置为中心缩放。选择工具下，版面超过可见范围时，可在无标注处按住左键拖动平移；对象和控制点优先响应编辑。空白单击取消选择，实际平移保留选择。中键平移继续可用。

## 只读原图查看

点击“查看原图”后，画布显示“查看原图 · 只读”，隐藏标注和控制点，暂停绘图、属性修改、删除、移动、粘贴标注和撤销。缩放、平移、切换图片、保存和导出仍可使用。PNG 导出仍包含完整标注结果。

点击“返回标注编辑”，或在画布按 Esc，恢复编辑。进入原图模式会取消未完成的绘制，已经完成的标注保持不变。

## 圆形局部放大

选择“局部放大”或按 M，从原图目标区域中心拖到圆边，创建取样圆。程序在附近放置默认 2× 放大圆，创建后适应窗口；靠近图像边缘时约束取样范围，保证取样圆位于原图内。

在选择工具下，拖取样圆内部移动取样区，拖放大圆内部移动展示位置。拖连接线或按 Option 拖圆内区域可移动整组。取样圆边控制点调整半径，放大圆边控制点调整倍率；右侧可输入半径、1.25×–8× 倍率及取样中心 X/Y。

右侧“分别设置线条”提供“取样圆”“连接线”“放大圆”三处独立样式，每处分别记录颜色、线宽、虚线和对比描边。点击画布相应部位也会切换样式面板，改动一处不会覆盖另外两处。

移动、调整尺寸、复制、方向键微调和 CLI 修改使用同一留白规则。放大对象超出原图时补足四周留白，扩展左、上留白时保持原图在屏幕上的位置；移回原图不会自动缩小已有留白。可点击“适应窗口”查看完整版面。放大对象保留复制、锁定、隐藏、层级和撤销功能。

放大内容来自方向校正后的原图，不包含其他标注，不增加原始照片细节。坐标与半径按原图像素保存。

## 保存、导出与版本迁移

Command+S 保存当前可编辑项目。原始文件、方向校正后的 `display.png`、`project.json`、历史修订和导出副本位于用户目录的 `data/projects/项目ID/`。PNG 默认按原图加留白尺寸重新渲染，也可选择 2× 或 4×，不会输出控制点。输出最长边 16384 px、总计 6400 万像素，实际处理能力还取决于内存。

PNG、便携包和标注清单通过浏览器下载。保存位置及是否弹出另存为由浏览器设置决定；“已发起下载”表示文件已交给浏览器，请在下载列表确认。PNG 同时在项目 `exports/` 目录保留一份。内置思源黑体随包提供；Windows 项目使用微软雅黑、宋体等字体时，请在 Mac 安装对应合法字体，或明确改为内置字体后再导出，换字体可能改变换行。

从 Windows v2.1-webui、v2.1-p 或旧 Mac 版本迁移时，先逐张保存并导出 `.biozip`，再在新版本打开并保存。v2.1-macweb 使用独立数据目录和浏览器草稿库，不自动复制旧版本数据。未添加局部放大的旧项目保持 version=1；添加局部放大后使用 version=2，三处独立样式须用 v2.1 或更新版本继续编辑。请保留迁移前的便携包。

| 操作 | 按键 |
| --- | --- |
| 打开 / 保存当前项目 | Command+O / Command+S |
| 撤销 / 重做 | Command+Z / Command+Shift+Z |
| 复制 / 粘贴 / 生成副本 | Command+C / Command+V / Command+D |
| 多选 | Command+点击，Ctrl+点击兼容 |
| 删除标注 | Delete（Backspace）或 Fn+Delete；输入框内正常编辑文字 |

| 取消绘制 / 返回编辑 | Esc |

## 退出、草稿与多个窗口

“退出程序”会提示未保存内容，保存当前窗口全部标签页草稿后请求停止服务；草稿保存失败时保留页面并提示错误。直接关闭网页或启动终端窗口不会停止服务。需要用脚本停止时，先在所有页面保存，再双击 `停止.command` 并输入 `y`。

同一服务连接的所有浏览器窗口都会随停服断开；退出入口无法替其他窗口保存草稿。重启服务后，原有其他页面需刷新才能取得新会话。草稿与浏览器、配置、网址和端口有关，应使用同一浏览器的普通模式；清除网站数据或换浏览器会影响恢复。刷新不恢复撤销记录，草稿不能代替显式保存或便携包备份。

每个用户配置在首次成功准备时记录固定端口。后续端口被其他程序占用会提示处理，不自动换端口，以便保留草稿来源。

## 本地目录、日志与故障处理

默认目录是 `~/Library/Application Support/Bio-Picture-Editor/v2.1-macweb/`，与 v1.1-macweb 的 `macweb/` 分开。

| 内容 | 默认目录下的位置 |
| --- | --- |
| 项目、原图、历史和 PNG 副本 | `data/projects/` |
| 编辑器、字体和 Mac 图片处理组件 | `components/v2.1-macweb-资源哈希/` |
| 独立运行时 | `runtime/node-v22.23.3-arm64/` |
| 官方下载缓存 | `downloads/` |
| 当前组件 / 固定端口 | `active-install.json` / `desktop-settings.json` |
| 日志 | `install.log`、`desktop.log`、`server.log`、`server-error.log` |

双击 `打开日志.command` 打开用户目录。初始化失败时检查网络、磁盘空间、目录权限与日志，然后重新启动。运行时或组件损坏时，启动器会校验并尝试修复；发布包损坏需重新完整解压。用户的 `data/` 项目不作为修复缓存删除。浏览器未自动打开时，可按启动窗口中的地址手动访问。

独立验证目录可用 `bash ./启动.command --profile "$HOME/Desktop/BioMacWeb-v2.1-Test"`。停止、CLI、日志脚本同样接受放在命令最前面的 `--profile`。初始化前需联网；测试配置独立保存项目，浏览器草稿仍由其端口区分。

完整 CLI 操作见随包 `Codex协作指南.md`；后续人工验证见 `Mac验证清单.md`。支持范围仍为普通 8 位 PNG/JPEG，不支持 TIFF、DICOM、全切片、多通道、高位深、CMYK、多页图片、多图拼版、批量导出或自动识别。编辑器在本机处理图片，不自动上传给模型，医学名称和区域判断由用户复核。
